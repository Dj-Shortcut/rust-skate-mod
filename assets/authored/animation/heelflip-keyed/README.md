# Heelflip authoring inputs

Family-specific inputs for `scripts/author_skate_heelflip_hybrid.py`.
`captured-body.json` retains this Heelflip take's monocular retarget observations;
`heel-constraints.json` records the authored interpretation and phase/contact
estimates. They are animation controls, not calibrated mocap or the source video.

The own project skateboard/sole dimensions and fixed-chain math are shared with
the existing rig. No Kickflip choreography or captured body is relabelled.
See `docs/RUST-SKATE-HEELFLIP-SOURCE.md` for source frames and open validation.
Generated packs remain unreviewed and stay outside the tracked tree.
