# Cole BS Pop Shove-it source candidate

This is a new, unreviewed source candidate for the existing `bs-pop-shove-it`
movement. It uses its own black-shirt Cole take from
[the BATB12 source](https://www.youtube.com/watch?v=YcmPDIj2BFo&t=128),
not a relabelled flip or a pose copied from Kickflip/Heelflip/Tre.

The cached source sequence shows a landed half-turn of the board with grip up,
no longitudinal flip and no body spin. The front foot lifts away; the rear foot
pops and scoops. The small hop and its body directions remain this take's own
source basis. Monocular depth, precise sole release and first-catch contact are
estimates. Filmed anatomical stance remains unverified; Regular/Goofy refer to
the canonical runtime mapping until the frozen model is checked visually.

The source window is frames 128–152 of a 29.97002997 fps cache starting at original
video 124 s (128.271–129.072s in the original video). The previous 128–180 capture
and its complete footage are retained privately. The shorter library edit keeps
Load, Pop, Air, Catch, Land and about 0.75 s of recovery at a 0.6 s physical flight.

The board recipe is canonical yaw +180°, native Shove −180°, Flip 0 and Body 0.
Contacts use the project's own curved deck and measured neutral charge shoe
geometry. The source body's complete former board translation is removed once;
the live physical carrier supplies the real jump and forward movement. Only a
vertical body-fit projection keeps the unchanged foot targets reachable, followed
by the existing fixed-length leg solve. These are authored reconstructions,
not calibrated 3D motion or increased detector confidence. Dense interpolation
does not create extra observations.

The exact adapter requires ID `bs-pop-shove-it-source-keyed-v1`, the existing
movement and the full Ollie / Flip 0 / Shove −180 / Body 0 signature. It derives press
release from this clip's 135→137 events, joins the body at its own Air 137, and
requires an actually observed ground plane. The existing whole 13-part support
hull bounds any coupled pose/board floor correction to 0.12 m; missing ground,
excess correction or unreachable limbs refuses capture. Physics, scoring,
contacts, reach limits and other keyed families retain their behavior.

Run with an existing Python/NumPy environment and the pinned original private
canonical capture JSON:

```sh
python scripts/author_skate_bs_pop_shove.py \
  --input "$PRIVATE_BS_SOURCE_JSON" \
  --output context/artifacts/bs-pop-shove-source-keyed/output
```

Parsing and strict binary encoding finish before output mutation. JSON and pack
are each written to a temporary file and atomically replaced; an encode/write
failure preserves the previous reader-valid pack. Output cannot overwrite an
ancestor directory containing its input. No video, game asset, raw detections,
private source pose or generated pack belongs in GitHub.

`Reviewed=false` remains on the original and reconstructed source. An isolated
TEST-ONLY-NOT-FOR-INSTALL copy can exercise the bounded reader and actual normal
route. A chosen gamepack must select this ID **instead of** the old
`backside-pop-shove-it-batb12-cole` for this movement; do not approve both.
No approval is generated by the baker. Source/mesh comparison, whole motion,
both profiles/stances and native Shadow testing remain open.
