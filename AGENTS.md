# Agent instructions

The repository instructions are in [AGENT.md](AGENT.md). Read it first, then
the standing project authorization and agent coordination in
[docs/AUTONOMY.md](docs/AUTONOMY.md).

The human project owner decides all current agent assignments. Follow the
owner's latest explicit direction; historical handoffs do not assign work.

When an agent uses a browser on the owner's Mac, it keeps to one tab: open the
first page in a tab of its own and load every later page in that same tab
(navigate, do not open a new tab or window). Open tabs cost the Mac memory and
the owner has asked for this (30 October 2026).
