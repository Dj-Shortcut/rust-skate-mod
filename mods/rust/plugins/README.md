# Server plugins (Oxide)

- [ShortcutSkate](SKATE.md): the skate mod's server component (park pieces, building, movement acceptance). Install it with [add-skate.sh](../server/add-skate.sh); see [LINUX.md](../server/LINUX.md).
- `ShortcutSkateProbe.cs`: admin-only diagnostic probes used during development.

The earlier ShortcutLoadouts (MW2 gunplay) plugin was removed on 25 October 2026; it is on the `archive/mw2-rewrite` branch.
